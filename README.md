# Career Ghana Internship Projects

This repository collects the three completed internship projects in separate folders:

- `weather-frontend/` — Weather application (Vite)
- `trivia-quiz-game/` — Trivia quiz game (Vite)
- `movie-recipe-finder/` — Movie and recipe finder (Vite)

Each folder contains that project's source, README, package manifest, and lockfile. Run `npm install` and `npm run dev` from the individual project folder to work on it, or `npm run build` there to build it.

Secrets and local-only files such as `.env`, `node_modules`, and build output are intentionally not included. Configure required API keys through the hosting provider's environment variable settings.
